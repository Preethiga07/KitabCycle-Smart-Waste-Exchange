# KitabCycle – Smart Waste Exchange

## 1. Introduction

KitabCycle is a smart platform designed to encourage the reuse and exchange of books. It helps students give away, exchange, discover, and request books instead of throwing away books they no longer need.

## 2. Problem Statement

Many students have books that they no longer use, while other students may need the same books. Without a proper platform, useful books may remain unused or be discarded.

KitabCycle provides a platform where students can list books, browse available books, request books, and find suitable exchange opportunities.

## 3. Objectives

- Encourage the reuse of books.
- Reduce unnecessary book waste.
- Help students find useful books.
- Make book exchange easier.
- Promote a sustainable sharing system.

## 4. Features

- Student Login
- Browse Books
- Book Requests
- List a Book
- Exchange Matching
- Favourite Books
- Campus Impact
- KitabCycle AI Assistant

## 5. Technologies Used

- HTML
- CSS
- JavaScript

## 6. How the System Works

1. The student opens the KitabCycle website.
2. The student logs in.
3. Available books can be browsed.
4. A student can list a book they want to give away or exchange.
5. Other students can request available books.
6. The system helps users find suitable exchange opportunities.
7. Students can save favourite books for later.

## 7. How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. The KitabCycle website will be displayed.

## 8. Conclusion

KitabCycle provides a simple digital platform for reusing and exchanging books. It helps students share useful resources, reduce waste, and support a more sustainable campus community.
